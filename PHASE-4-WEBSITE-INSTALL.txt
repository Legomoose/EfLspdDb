EFLSPDDB PHASE 4 WEBSITE UPDATE

Prerequisites: Phase 4 Supabase migration and Phase 4 Worker already deployed and existing login tested.

1. Back up current GitHub files.
2. Extract this ZIP, upload its contents to the root of Legomoose/EverFallLspdDb and commit.
3. Wait for Cloudflare Pages deployment, hard refresh, sign in with existing Owner code.
4. Open the top-right user dropdown > Manage Accounts.
5. Test viewing accounts, roles, permissions and a test detective account before real users.
6. Test temporary-code login and mandatory code change on a TEST account, not your Owner account.

NOTE: Photo URLs are supported but direct photo upload to Supabase Storage is NOT implemented. The profile photo field accepts a publicly reachable HTTPS image URL. Do not put confidential photos at public URLs.
NOTE: Cases, gangs, pins, contacts and uploads remain browser-local and are NOT shared via Supabase. Role permissions for those records cannot be enforced server-side until shared data APIs are built.
NOTE: New accounts may require a code change on first login. Account resets revoke old sessions.
